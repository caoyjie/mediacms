# 用户文档

## 上传媒体

点击 **Upload**，进入上传页面后点击 **Browse**，选择媒体文件并等待上传完成。上传过程中可以暂停，之后继续。媒体进入处理和转码队列后，点击 **View media** 查看媒体，或点击 **Edit Media** 补充标题、描述、标签、分类、海报和其他元数据。

## 下载媒体

管理员需要在配置中启用下载功能。媒体页面显示下载按钮后，用户可以选择可用的编码版本下载；视频通常需要对应转码任务成功后才会出现。

## 添加字幕

在媒体页面点击 **EDIT SUBTITLE**，上传 `.vtt` 字幕文件并选择语言。保存后，播放器可在字幕菜单中启用对应字幕。系统也支持通过 Whisper 自动生成转录内容（具体取决于部署配置）。

## 时间戳分享

可以在媒体 URL 中加入时间戳，使打开页面后从指定时间开始播放；也可以在评论中使用时间戳，方便其他用户跳转到对应位置。

## 评论中的用户提及

在评论中输入 `@` 并选择用户即可提及对方。被提及用户可能收到通知，具体取决于通知配置。

## 在时间轴显示评论

评论可以关联播放时间点，并在视频时间轴上显示。点击时间轴标记即可跳转到对应评论位置。

## 搜索、分享与嵌入

使用搜索框查找标题、描述、标签和字幕内容。媒体可以通过公开链接、不公开列出链接或权限分享；媒体页面的嵌入功能会生成可放入其他页面的播放器代码。

## 个人资料

在个人资料页面可以修改头像、显示名称、简介及其他可配置选项。管理员可能根据站点策略限制部分字段。

## 裁剪视频

在媒体编辑页面进入视频编辑器，设置开始和结束时间，或将视频拆分为多个片段。可以保存为新媒体、替换原媒体或创建独立片段，具体选项取决于用户权限。
